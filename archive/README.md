## Archive rules

- Archived documents are not automatically authoritative.
- Do not delete preregistrations, experiment outcomes, falsifiers, founder decisions or unique research merely because they are old.
- When archiving, preserve the full content and record original path, date and reason.
- If a current document references an archived file, update the reference only after checking the intended historical context.
