# ADR-001 — Roadmap v3.0 Phase 0 M0.5 Read-Only Causal Trace

**Status:** Implemented and merged to `main`  
**Decision date:** 27 November 2026  
**Merge commit:** `612022e81f749a99de665372704d7acc0645de67`  
**Scope:** Roadmap v3.0 Phase 0 M0.5 only. This ADR is not an approval for Phase 1 or runtime activation.

## Context

The Master Roadmap v3.0 Phase 0 M0.5 requires a default-OFF collector with explicit `trace_id` and `parent_ids` across input arrival, candidate generation, salience/workspace selection, Gate outcome, SQLite Writer delta and output. It requires one Fountain and one Chat trace sample and paired testing that confirms prompts, confidence and selection order are not mutated when tracing is enabled.

The collector must not become a decision input or a second substrate store. Live runtime evidence must remain explicitly unknown until a separately authorised live run exists.

## Decision

Implement `influence_trace.py` as a cross-cutting observational sidecar and integrate it at existing producer/consumer seams.

1. **Default OFF:** `NEX5_TRACE_OVERLAY` unset or `0` creates no trace context and performs no trace-file I/O.
2. **Sidecar only:** append JSONL to `logs/nex_causal_trace.jsonl` by default. The recorder rejects unsafe/non-JSONL destinations and never writes to substrate SQLite.
3. **Explicit lineage:** every event has `trace_id`, `event_id`, `parent_ids`. Parent edges are passed by call sites; sequence/time alone never creates a causal edge.
4. **No extra substrate reads:** callers pass values already in scope. The collector does not read NEX databases and is not consulted by a decision path.
5. **Privacy-conscious payloads:** text-bearing fields are reduced to SHA-256 digest and UTF-8 byte length; raw prompts, beliefs, replies and generated thoughts are not stored.
6. **Evidence honesty:** fixture/test traces are L3. L4 is only emitted under an explicit runtime capture context, which was not enabled in this work.

## Integrated paths

- **Fountain:** readiness, retrieved candidate identifiers/source types, workspace selection, prompt assembly, output filtering/retry, quality/Gate outcomes, sense/dynamic/belief writes, crystallization link and speech-queue outcome. Non-standard paths that bypass generation/crystallization are labelled separately.
- **Chat:** input/session/message writes, membrane routing and retrieved candidates, faculty workspace selection, final prompt assembly, tool/voice path, assistant-message write and response. The belief crystallization Gate is N/A for a Chat reply.

The Coherence Gate's persisted `beliefs.gate_decisions` row is traced with its row ID and a parent edge to the preceding quality-gate event.

## Alternatives rejected

- **Write trace rows into a substrate database:** rejected because it mutates the state being observed and creates coupling between instrumentation and the cognitive substrate.
- **Infer parents by timestamp or sequence:** rejected because chronological adjacency is not causal proof.
- **Persist raw prompt/output text:** rejected in favor of hashes, lengths and bounded categorical metadata.
- **Turn the overlay on in a live process:** not authorised or required for the source/test increment.

## Consequences and limits

- The collector is reversible and inert by default.
- When explicitly enabled, synchronous local JSONL appends can add I/O latency. Paired tests establish semantic state equivalence, not timing equivalence.
- CI evidence is L3 fixture/test evidence only. There is no live L4 trace.
- JSONL retention/rotation is not implemented; it is a sidecar that should remain OFF unless an authorised bounded capture is planned.
