Step 3 -- DEDUP to top-10 "distinct" (lines 2716-2743):
  _DEDUP_TH = 0.5
  def _first_sentence_grams(_t):
      _s = re.split(r"(?<=[.!?])\s+", (_t or "").strip())
      _w = re.findall(r"[a-z0-9']+", (_s[0] if _s else "").lower())
      return {tuple(_w[i:i+5]) for i in range(len(_w) - 4)}
  _kept_rows, _kept_grams = [], []
  for _r in _ranked:
      if len(_kept_rows) >= 10:
          break
      _g = _first_sentence_grams(_r["thought"])
      _dupe = False
      for _kg in _kept_grams:
          _u = len(_g | _kg)
          if _u and len(_g & _kg) / _u >= _DEDUP_TH:
              _dupe = True
              break
      if _dupe:
          continue
      _kept_rows.append(_r)
      _kept_grams.append(_g)
  -- greedy, highest-score-first; a candidate is dropped ONLY if its
  FIRST SENTENCE'S 5-gram set overlaps an already-kept one by >=50%
  (Jaccard-style ratio on 5-grams of the first sentence only, not the
  whole thought, and not any topic/entity label). This is a SURFACE-TEXT
  near-duplicate filter, not a topic-aware one.

Step 4 (after this round's scope, but relevant to why "observed" in Task

-- Method (B.1) --
For every fire where the mechanism fired (identified by a
"Recent voice of yours..." prefix in fountain_prompt_blocks), with a
non-null focal_item (fires with no focal_item cannot be scored "same-
topic" against anything and are excluded, same convention as prior
rounds):
  1. Rebuilt that fire's EXACT real-time shortlist using the identical
     SQL window + dedup logic quoted in Task A, with `now` set to that
     fire's own real ts (not the live clock) -- all genius_tags STRIKING
     rows and all fountain_events thoughts were preloaded once and
     sliced with a binary search on tagged_at for speed; this reproduces
     the live code's query exactly, just offline and read-only.
  2. Classified each shortlist candidate as same-topic or not by checking
     whether its OWN full thought text contains any distinctive (>=4
     char) word from the CURRENT fire's own focal_item -- exact substring
     containment, not a similarity score.
  3. N = shortlist size (post-dedup, <=10), K = same-topic count within
     it, n = min(2, N) (the real draw size). Computed the hypergeometric
     probability of drawing at least one same-topic item in n draws
     without replacement from a pool of N with K same-topic:
       P(>=1) = 1 - C(N-K, n) / C(N, n)   (= 1.0 if N-K < n)
  4. Matched the fire's REAL stored quote (fountain_prompt_blocks prefix)
     back to the specific shortlist candidate it came from (by matching
     the start of the stored quote text against each candidate's own
     thought, within that fire's own small reconstructed shortlist --
     not a corpus-wide search, so no cross-fire ambiguity), and recorded
     whether THAT specific candidate was same-topic -- this is the
     OBSERVED outcome, reflecting everything that actually happened
     end-to-end (draw + the groove filter downstream of it), not just the
     draw in isolation.
