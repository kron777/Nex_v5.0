## B. Mechanism — computation or corpus

### B.1 NOT a computation artefact — structurally impossible — OBSERVED

```python
def feat_self_witnessing(thought):
    cl = (thought or "").lower()
    n = max(1, len(re.findall(r"[.;!?]+", thought) or [thought]))
    hits = sum(1 for pat in SELF_WITNESS_PATTERNS if re.search(pat, cl))
    return min(1.0, hits / max(1, n))
```

`SELF_WITNESS_PATTERNS` is an **18-element hardcoded module constant** (`score_v2.py:36`). F4 takes no corpus, no window, no reference set — it is a pure function of the one string. **The C3 test that exposed `anti_template` cannot be applied here because there is no reference to freeze.** This also matches R39 §C's structural point: *"F1, F4 and F5 are pure functions of the fire itself. Only F2 and F3 depend on rolling state."*

So F4 is measuring something that really changed in the fires. **But it is not self-witnessing that changed.**
