## D. Fix shape — design only, and §E is why it stays design

### D.1 Smallest changes that would let semantic edges accumulate

- **Harmonizer:** one clause — `ORDER BY tier ASC` → order by recency, or carry a cursor. That is the entire fix for the window.
- **`edge_generator`:** rescale the three gates to the measured distribution — `opposes` j > 0.3 → ~0.12 (p99), `supports` 0.4 → ~0.15, `refines` 0.5 → ~0.18. One constant each.

### D.2 The damper — MANDATORY per R44/R45, and the honest answer is mixed

- **Harmonizer: a damper exists.** `mark_paradox` is explicitly first-pass — it writes the edge, logs, sets disturbance, and *"does NOT pause or retire beliefs"*; escalation requires incubation. Bounded by design.
- **`edge_generator`: NO damper exists, and there is a positive loop.** `opposes` carries the highest multiplier (`j × 0.8`), so a rescale shifts the type mix toward it. More `opposes` → higher `_contradiction_pressure` → the drive weighting tilts toward contradiction-seeking → more conflicting material → more `opposes`. **`MAX_EDGES_PER_BELIEF = 5` caps per-belief fan-out but does nothing about that loop.** Naming it as required: **there is no damper on the contradiction-pressure loop today, and one would have to be built before any threshold rescale.**

### D.3 Offline prediction — OBSERVED

- **Harmonizer window fix:** **1 conflict per 200-belief scan** (measured, 19,900 pairs). Against ~0 today, but 1 per scan is not a working contradiction detector.
